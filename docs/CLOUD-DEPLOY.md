# 交易主机部署方案（阿里云 ECS / 本地 Windows）

> 目标：让 fresh_ma 在无人值守的 Windows 上每天自己跑完。
> 本文解决两件事：**哪些我能替你做掉**，**剩下的为什么必须你本人**。

---

## 一、边界：我能自动化的 vs 必须你本人的

| 环节 | 谁做 | 为什么 |
|---|---|---|
| 开 ECS、建 VPC/安全组、选镜像 | **我**（给 AK 后，脚本已就绪） | 纯 API 操作 |
| 系统初始化（自动登录 / 电源常开 / 关 Windows 更新自动重启） | **我**（云助手远程执行） | `bootstrap.ps1` |
| 部署看门狗、注册计划任务、配告警 | **我** | 同上，不需要远程桌面 |
| 传送策略文件、日常巡检、拉状态 | **我** | `provision.py cmd / deploy / status` |
| **下载 QMT 安装包** | 你 | 券商专属版本，需登录券商官网拿 |
| **装 QMT + 登录资金账号** | 你 | 交易密码、验证码不该经我手 |
| **向券商报备设备与 IP** | 你 | 云主机 IP 属机房，不报备可能被风控拦 |
| **首次实盘确认**（空仓接入、先下 1 手） | 你 | 真金白银前的最后一道，谁都不能代签 |

**一句话**：我能把机器准备好到"你只需要装 QMT、登录、点运行"，但最后这三步是身份与合规问题，绕不过去。

## 二、先选路线：云主机 还是 家里一台迷你主机

| | 阿里云 ECS | 家里迷你 Windows 主机 |
|---|---|---|
| 一次性成本 | 0 | ¥1200–2000（N100/16G 级别） |
| 持续成本 | 约 ¥300–600/月（含 Windows License） | 电费约 ¥10/月 |
| 回本周期 | — | **6–10 个月** |
| 可用性 | 高：不掉电、不断网、99.9%+ | 家里断电/断网就断 |
| 券商报备 | **机房 IP，部分券商风控会拦**，需提前加白名单 | 家庭宽带 IP，通常更容易通过 |
| 延迟 | 多一跳（日频策略，无所谓） | 本地直连 |
| 上手速度 | 几分钟就有机器 | 要买、等快递 |

**我的建议**：日频策略对延迟零要求，但对"别断"要求高。
- **先验证阶段用云主机**：随时开随时退，跑不通不亏；
- **跑顺 3 个月后转迷你主机**：一年省下三四千，且家庭 IP 报备更顺。
- 如果你家里已有一台常开 Windows，直接用它，最省事。

## 三、云主机上的三个特有坑（物理机没有）

1. **GUI 程序必须有人登录才跑** → 必须配开机自动登录（脚本 `-AutoLogon` 已做）。
   这也是"重启后 QMT 能否自己起来"的前提。
2. **远程桌面断开 ≠ 注销** → 断开会话后 QMT 通常继续跑，但**必须实测**；
   若断开即停，改用 VNC 或保持 RDP 最小化连接。
3. **Windows Update 半夜重启** → 脚本已改策略为"下载但通知，不自动重启"。
   这一条不处理，你会在某个周一早上发现周五之后就没跑过。

## 五、给我阿里云权限的正确姿势（重要）

**不要给主账号 AK，不要给登录密码。** 给一个能随时掐掉的 RAM 子账号：

1. 登录 RAM 控制台 → 身份管理 → 用户 → 创建用户
2. 访问方式勾选 **编程访问**（不要勾控制台登录）
3. 授权：
   - 只想让我巡检：`AliyunECSReadOnlyAccess`
   - 要我开机 + 部署：`AliyunECSFullAccess`（放开前想清楚费用）
4. 生成 AccessKey，把 ID/Secret 发我
5. 用完后在 RAM 里**禁用或删除**这个用户即可

我用的时候只在命令行 `export`，**不写进任何文件、不进 git**。

## 六、部署流程

### A. 我来做（你给 AK 之后）

```bash
# 0. 只认环境变量，不落盘
export ALIYUN_ACCESS_KEY_ID=...
export ALIYUN_ACCESS_KEY_SECRET=...

# 1. 先验权限 —— 只读、免费
python3 scripts/aliyun/provision.py check

# 2. 挑规格与镜像（拿 ImageId）
python3 scripts/aliyun/provision.py images --region cn-hangzhou
python3 scripts/aliyun/provision.py types  --region cn-hangzhou --filter u1

# 3. 询真实价格（不扣费）
python3 scripts/aliyun/provision.py price --region cn-hangzhou --type <规格> --image <镜像>

# 4. 创建（默认 dry-run，必须 --yes 才花钱；--allow-ip 强烈建议带）
python3 scripts/aliyun/provision.py create --region cn-hangzhou --zone cn-hangzhou-k \
    --type <规格> --image <镜像> --password '<复杂密码>' --allow-ip <你家公网IP> --yes

# 5. 等它 Running
python3 scripts/aliyun/provision.py status --region cn-hangzhou

# 6. 送文件 + 初始化（云助手，不用远程桌面）
python3 scripts/aliyun/provision.py deploy --region cn-hangzhou \
    --instance <实例ID> --src qmt/watchdog --yes
```

### B. 你来做（我替代不了）

1. 券商官网下载 QMT 安装包，装到云主机
2. 登录资金账号，**勾选"记住密码 / 自动登录"**，把策略粘进去并设为自动运行
3. 打电话给客户经理：**报备这台机器的 IP 与用途**
4. 首次接入必须**空仓**，先下 1 手验证全链路

## 七、验收清单（部署完逐条打勾）

| # | 检查 | 命令 / 动作 | 通过标准 |
|---|---|---|---|
| 1 | 日志路径命中 | `python watchdog.py --probe-logs` | 至少一个候选路径有文件 |
| 2 | 三级心跳正常 | `python watchdog.py --status` | L1 在、L2 心跳 <35 分钟、L3 有 `[done]` |
| 3 | 告警能发出来 | 手工触发一次 | 企微收到消息 |
| 4 | 自动重启有效 | 任务管理器杀掉 QMT，等 6 分钟 | 进程自己起来 + 收到告警与恢复通知 |
| 5 | **重启后策略自动运行** | 重复第 4 步，看是否继续出 `[hb]` | 有 `[hb]` 才算真无人值守 |
| 6 | 远程桌面断开后仍在跑 | 断开 RDP，半小时后看日志 | 心跳不中断 |

**第 5 条是全局最大未验项**：若券商版本不支持重启后自动运行策略，
看门狗就降级成"及时发现 + 通知你"，替不了你点那个"运行"按钮。
结论出来之前，不要上真钱。
