# 基金持续性研究 · 口径与脚本链路

回答一个问题：**按历史排名选基金，能不能赚到钱。**

结论先放这里：**选谁不行，避谁可以。** 正面预测（梯队、冠军、中游、低波动、规模甜蜜区）扣成本后全部不显著；
负面预测（回避 >80 亿、指增后 30%）反复成立。

页面：`策略研究 → 基金持续性`（`/#fund`），数据源 `/api/v1/fund/persistence`。

## 一、数据口径

| 用途 | 表 / 文件 | 口径要点 |
|---|---|---|
| 净值 | `fund_research.db.fund_nav_daily` | 日频复权净值，2015-01 ~ 最新。折叠成年度/月度面板时**按「每期最后一个有净值的交易日」取，不按日历日**（2022-12-31、2023-12-31 是周末） |
| 年度面板 | `fund_nav_year_d` / `fund_nav_month_d` | 由上一行折叠而来。`fund_nav_year_d` 的 2014 年列来自旧的年截面表（日频抓取起点是 2015-01），与日频重叠区偏差为 0 |
| 持仓 | `data/holdings/by_fund/*.csv` | `disclosed`（披露）+ `carried`（从上次全披露结转）。Q2/Q4 全披露约 100%，Q1/Q3 前十大约 35% + 结转约 40% ≈ 股票仓位 |
| 行业 | `fund_industry_exposure` | **Q2/Q4 才是 100% 全披露，Q1/Q3 只到约 55%**。归因只用 Q2/Q4 |
| 回归隐含 | `fund_regression_holdings.bayes_w` | 只覆盖「季报看不见的那部分」（约占净值 35%），**不是全持仓**，别当全组合用 |

三条硬纪律：

1. **显著一律用「期序列」做 t 检验，不用 pooled 观测。** 同一只基金跨年重复出现，pooled 会把 t 放大 5–13 倍
   （实测：Top5% 次年超额 pooled t=6.41，改成年度等权后 0.77）。
2. **持仓类结论的建仓日必须推到披露期限之后**：Q1/Q3 后 15 个交易日，半年报 45 个，年报 60 个。
3. **归因只用 `disclosed`；`carried` 只用于「抄作业」这类策略构造**（因为实盘抄作业本身就必须假设「还拿着」）。

## 二、脚本链路（都在 `backend/scripts/`）

```
build_nav_year_from_daily.py    日频 → 年度/月度面板（写 fund_nav_year_d / fund_nav_month_d）
        ↓
build_fund_stats.py             主统计 → fund_stat_cache['persistence']
                                （分组体检、梯队超额、迁移矩阵、持有期衰减、经理层、规模）
check_fund_sample.py            [校验] 日频子集 vs 全样本，证明换源不改变结论
build_fund_brinson.py           行业配置 vs 选股（只 Q2/Q4 全披露）→ res_brinson.json
build_fund_copy_backtest.py     抄作业·季度全组合（主口径）→ res_copy_q.json
build_fund_copy_backtest_implied.py  抄作业·半年隐含 35%（交叉验证）→ res_copy_holdings.json
build_fund_freq_cost.py         换手频率 × 成本 → res_freq_cost.json
refresh_fund_strategies.py      重跑 5 个基金策略 → res_strategies.json → 回写 backtests 表
patch_stat_cache.py             把上面几个 JSON 按 key 合并回 fund_stat_cache
```

**顺序很重要**：`build_fund_stats.py` 会**整份覆盖** `persistence` 这一行，所以必须在它之后再
用 `patch_stat_cache.py` 把其它块合并回去，否则页面上的持仓/成本块会被冲掉。

`patch_stat_cache.py` 只能在容器内跑，否则会和后端抢 WAL 写锁：

```bash
docker exec -i quant-backend python /app/scripts/patch_stat_cache.py merge < blocks.json
```

统计工具 `_fund_stats.py`：平台 venv 装不上 scipy，用不完全贝塔函数自己实现 t 分布。

## 三、关键结论与样本

| 结论 | 样本 | 数字 |
|---|---|---|
| 10 年年化 ≥20% 极少 | 689 只完整十年 | 只有 1 只（0.15%） |
| Top5% 次年超额 | 10 个年度 | +3.19%，t=0.77，6/10 年为正 |
| 30–50% 组最稳 | 10 个年度 | +1.83%，t=2.01，σ 2.87（Top5% 是 13.15） |
| 迁移矩阵 | 10 个年度 | Top5% 只有 11.5% 留在 Top5%，30.8% 掉进后 30% |
| 排名保鲜期 | 142 个月 | Top5% 留存 1 月 12.6%(2.5× 随机) → 12 月 9.0%(1.8×) |
| 换手频率 × 成本 | 142 个月 | 月度毛超额 +9.30%，年成本 7.80%，净 +1.50%(t=0.36) |
| 规模 2–10 亿 | 10 个年度 | +2.32%，t=4.61；但扣 0.65% 成本后 +0.48%(t=0.49) |
| 回避 >80 亿 | 7 个年度 | −3.22%，t=−1.57；回测 −3.06%，t=−2.19 |
| 抄作业（季度全组合） | 34 个季度 | 选股效应 +1.96%(t=1.38)，β 调整 α=−0.25%(t=−0.23) |
| 抄作业（半年隐含 35%） | 16 个半年 | 选股效应 +5.82%(t=1.80)，β 调整 α=−0.77%(t=−0.29) |
| 行业 vs 选股 | 18 个半年 | 实际 +0.23%(t=0.16)、配置 +0.28%(t=0.30)、选股 −0.06%(t=−0.06) |

两个反直觉的点，值得记住：

- **「后 30% 最稳」是错觉。** 年度矩阵里后 30% 留存 34.8% 看着最高，但它的随机基线本来就是 30%（1.16×）；
  前 5% 留存 11.5% 却等于随机的 2.3 倍。按相对值看，好基金的排名比差基金稳。
- **抄作业的优势全是 β。** 组合对基金的 β=1.356、R²=0.903，抄出来是「高 β 版本的同一只基金」。
  未调整时看到的 +0.86~+2.63%/期，来自「100% 股票 vs 基金约 75% 暴露」，风险调整后归零。

## 四、统计功效（必须一起读）

年度 10 期、半年 16–18 期、季度 34 期。这个样本量**能可靠否定「明显有效」，
不足以断定「一定无效」**。

具体说：Top5% 的年度超额 +3.19%，年际标准差 13.15%。要证明 3pp 的超额显著（t=2），
需要的样本量远大于 10 年——所以「没测出显著」不等于「不存在」。本研究的结论是
「没有可用的证据」，不是「一定没有」。

## 五、已知限制

- `fund_nav_daily` 覆盖 9,057 / 13,852 只（缺 4,795 只低波动基金），换手频率检验的池子是 7,489 只主动权益
- `fund_regression_holdings` 的 Q2/Q4 期次不完整（回归只对披露不完整的期跑），要季度频率请走
  `by_fund` 的 disclosed+carried 口径
- `kline_daily` 个股行情自 2017-06 起，2017 年之前无法做持仓类回测
- 回测未计申购限额、暂停申购、赎回到账时间；实盘成本会更高
