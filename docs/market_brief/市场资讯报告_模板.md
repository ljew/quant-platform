## 填写规则（生成时必须遵守，不随报告输出）

### R1 · 时区、交易日与每日运行
- 全文统一**北京时间（UTC+8）**，生成时点在报告头写全。
- 美股必须写「美东 MM-DD 收盘 / 北京时间 MM-DD 凌晨」，**禁止只写一个日期**。
  日内跨夜最容易把「美东周四暴跌」错记成「周五暴跌」，本次已实际踩到。
- 自动化**每日运行（含周末）**。每次先判定 `是否交易日`：
  - **交易日**：按本时段正常取数。
  - **非交易日（周末/节假日）**：报告头标注「休市」+ 原因 + 下一交易日；第 2 节引用**上一交易日**收盘数据并逐项标日期，第 3/4 节改为「上一交易日回顾 + 休市期间消息面」，第 5 节观察点指向下一交易日，第 6 节以休市期间资讯为主。
    **严禁虚构当日行情、盘中快照、半日/全天成交额**；本时段确无新增行情要明写「本时段无新增行情」，不得用旧数据冒充新数据。
- 周一早间版覆盖窗口 = 上周五 A 股收盘 → 周一开前，含周末消息面与周五美股。周六/周日各版覆盖窗口 = 周五 A 股收盘 → 该版生成时点。

### R2 · 字段三要素（硬规则）
每个数字必须同时给出：**数据对应日期 + 口径 + 数据源标签**，三者缺一不进结论。
- 利率类尤其要写明口径：中债收益率曲线 10Y / 活跃券 260016 / 银行间收盘 / 美债 10Y，**不同口径不可混用比较**。
- 涨跌幅写清「相对上一交易日收盘」还是「相对结算价」（期货常用结算价，易差 1–2 个 tick）。
- 「-2.96%」这类**相对变动百分比**与「-2BP」不可混写，看到先换算再引用。

### R3 · 溯源标签（字段级，不写整篇一个标签）
| 标签 | 含义 |
|---|---|
| `[通达信✓]` | tdx-connector 实时/收盘快照 |
| `[tushare✓]` | Tushare pro API（收盘价/估值/指数日线） |
| `[neodata✓]` | 国泰海通 neodata-financial-search |
| `[腾讯✓]` | 腾讯 westock-data CLI |
| `[中债✓]` | 中国债券信息网日评（收益率曲线、公开市场） |
| `[公开媒体✓ 来源·日期]` | 财经媒体，必须带**来源名 + 发布时间**，机构观点必须带 publishTime |
| `[待补⚠]` | 未取到，**严禁估算或编造** |
| `[源冲突⚠]` | 多源不一致，已按来源层级采信；**只在该字段打标，不展开比对过程** |

### R4 · 源校验门（三源交叉，**动作必做、过程不展示**）
- 同一字段两源及以上一致 → 直接采信，**不标注**「多源一致」这类过程信息。
- 多源冲突 → **不自行拍板**：按「有无完整时点标注 / 有无交叉印证 / 来源层级」选定采信值，
  正文直接用采信值，仅在该字段挂一个 `[源冲突⚠]`（8 个字符，不展开各源数值）。
  **不再单列校验表** —— 读者只看结论，不看比对过程。
- 能做的跨市场换算校验要做（例：COMEX 黄金 USD/oz ÷ 31.1035 × USD/CNY ≈ 沪金 元/克），
  这是最便宜的假数据探测器；通过就不写，偏差超过 0.5% 才在当节小结里点一句。
- 涨跌家数按**交易所口径**相加（沪 + 深 + 北），**不得把创业板/科创板再加一遍**（属深/沪子集，重复计算）。

### R5 · 数据源优先级（v1.4 起调整，减少待补）

> ⚠️ **本节优先级高于 automation prompt 里的取数描述。** 若 prompt 仍写「费半/VIX 从公开媒体取」，
> 一律以本节的新浪接口为准；prompt 会在下次维护时同步，但不要等它。
| 数据 | 首选 | 说明 |
|---|---|---|
| A 股指数 / 个股 / 成交额 | 通达信 `tdx_quotes` | 实时与收盘快照 |
| **科创综指（000680.SH）· 北证50（899050.BJ）** | **tushare `index_daily`** | ✅ 已验证可取，**不许再标 `[待补⚠]`** |
| **美债 2/10/30Y** | **tushare `us_tycr`** | ✅ 已验证可取，比媒体转载准 |
| 中债收益率曲线 | 中债日评 + tushare | 两个口径不可混比 |
| 估值（PE/PB/市值） | tushare `daily_basic` | 须带日期 |
| 费城半导体（SOX）/ VIX | **新浪行情 `hq.sinajs.cn`** | ✅ 已实测可取，见下方接口 |
| 解禁 | 交易所公告 / tushare `share_float`（需逐股） | 聚合口径取不到就标 `[待补⚠]`，不估算 |

**新浪行情接口（费半 / VIX 的唯一可靠源）**

```
GET https://hq.sinajs.cn/list=gb_sox,znb_VIX
Header: Referer: https://finance.sina.com.cn/
（返回 GBK，需转码）
```

- `gb_sox`：费交所半导体股指数，字段为 `名称,收盘,涨跌幅,时间,涨跌额,开盘,最高,最低,52周高,52周低,...`。
  实测 11-06：`9390.25, +4.21%`，昨收 9011.14。
- `znb_VIX`：VIX 恐慌指数，字段为 `名称,收盘,涨跌额,涨跌幅,...,日期,时间,开,高,低,昨收`。
  实测 11-06：`25.63, -2.54, -9.02%`，昨收 28.17。
- **替代源全部试过、都不可用**，不要再浪费时间：
  yfinance（1.5.1 已装）→ Yahoo 限流 `YFRateLimitError`；Yahoo 直连 → sad panda 拦截页；
  stooq → JS 验证；东财 `m:100` 国际指数 63 个里**没有**费半与 VIX；腾讯 `usSOX`/`usPHLX` 无匹配、
  `usVIX` 数据停在 2026-09-15（陈旧，不可用）。

**2.1 境内表不允许留空**：20 日 / YTD / 成交额都可由 tushare `index_daily` 历史算出——
20 日 = 收盘 / 21 根前收盘 − 1；YTD = 收盘 / **上年最后一个交易日**收盘 − 1。
成交额用 `index_daily.amount`（单位千元，÷1e5 得亿元），注意它是**指数成分股口径**，
深成指（500 只）4650 亿 ≠ 深市总成交 8852 亿，两者不可混用。

### R6 · 内容边界（重要）
- 本报告是**信息收集与事实整理**，产出「状态判定 + 可验证的观察点/触发条件 + 资讯简述」。
- **不产出涨跌方向预测、不产出买卖建议；全篇不设裁决区、不设签字栏，不做方向裁决。**
  这与 `a-share-three-source-report` methodology §0「AI 不做最终裁决」一致。
- 方向性判断属发现类（F 通道），归 **A股研究团队**；验证类结论走衡析的假设卡流程。
  本报告不替代其中任何一条，也不得用资讯综述冒充研究结论。
- 引用机构观点必须是**原文可追溯**的公开表述，带来源与日期；不得概括成无名「机构认为」。

### R7 · A 股配色、格式与去重
🔴 涨 / 🟢 跌。表格优先，正文每段不超过 3 行。所有百分比保留两位小数，收益率用 BP 时标 BP。

**去重规则（硬）—— 同一事实只允许出现一次，重复即删：**

| 重复来源 | 处理 |
|---|---|
| 「核心读数 KPI 卡」与第 2 节品种全景 | **不设独立 KPI 模块**；关键数字只在第 1 节给结论、第 2 节给明细 |
| 第 1 节速览与第 2 节表格 | 速览写结论 + 1 个最异常读数，明细与计算过程留第 2 节 |
| 第 4 节状态判定与第 1/2 节 | 只写「五项读数同向 + 一句状态判定」，不重列数字表 |
| 第 6 节资讯简述与第 2/3 节 | **只写事件，不堆数字**；需数值时写「见第 X 节」 |
| 第 6 节「对应表」与第 1 节时序提示 | 同一对应关系只登记一次，另一处写「见速览时序提示」 |
| 章节规则声明与表后重复免责 | 规则只声明一次，表后不复述；免责统一放第 8 节 |

**HTML 版式**：section 内边距 ≤12px、表格单元格内边距 ≤4px、正文 13px / 行高 1.5、
section 间距 ≤9px；不设 KPI 卡片区；自包含、离线可渲染、浅色主题。

**交付与入库（生成后必做）**：`.md` 与 `.html` 写完后执行

```
python3 /Users/happyljew/quant-platform/backend/scripts/ingest_market_report.py --file <生成的 .md 绝对路径>
```

脚本按 `YYYYMMDD_时段` 幂等写入 `market_reports` 表并重建静态索引；返回 `ok:true` 才算交付完成。
入库失败须在完成摘要中写明，不得静默略过。

### R8 · 每节小结（v1.4 新增，硬要求）
每个带数据的章节（1/2/3）末尾必须有且**只有一句** `**小结**：…`，回答「这节数据说明了什么」；
第 4 节用「**小结（本节结论）**」替代原「状态判定」行，不另写第二条。

写法约束（越界即不合格）：
- **只描述状态与相对关系**。正例：「缩量普跌，卖压不重但买盘更弱，资金端逆势流入」。
- **禁止**：涨跌预测、概率、「利好/利空」「有望」「预计」「将启动」、买卖建议、目标位。
- **必须能被本节数字直接支撑**，不许引入本节没出现过的新事实。
- 一句话，**≤60 字**；不重复表格里的数字，只给结论。
- 数据互相矛盾时**如实写矛盾**（例：「量能收缩与 ETF 净流入并存，方向未一致」），不许强行统一叙事。
- 与第 4 节「状态判定」的分工：第 4 节是**全篇结论**，各节小结是**本节结论**，两者不得矛盾。

## 四时段侧重差异（同一模板，章节权重不同）

| 时段 | 触发 | 覆盖窗口 | 必重章节 | 第 6 节资讯配额 | 可略章节 |

| **早间版** | **每日** 06:45（7 点前） | 上一交易日 A 股收盘 → 今晨，含隔夜欧美、亚太、商品、周末消息 | 1/2/3/5/6/**8** | **20–32 条** | 4 简化为昨收状态 |

| **收盘版** | **每日** 15:30 | 全天 A 股收盘 + 当日亚太 | 1/2/4/5/6/**8** | **16–26 条** | 3 简写 |

> 每份报告必须能**独立读懂**，不得写「见早间版」。增量版也要重列核心数字。
> 周末/节假日四个时段照常出，但一律按**休市版**处理。休市版之间允许核心数字重复，
> **第 6 节资讯简述是主要增量来源**，须重新检索，不得照抄上一时段的资讯列表。

### 6.5 反注水规则（与配额同等硬）

- 一个事件**无论多少家媒体报道只算 1 条**，来源列全、合并叙述。

- 同一事实的正反两面不得拆成两条（如「涨 3%」与「涨幅收窄」）。
- 允许**快讯级**条目：一句话、无解读即可，不必每条都写影响分析。
- 纯行情数字（涨跌幅、成交额）不算资讯，除非本身构成事件（历史新高、熔断、涨跌停极值、成交额破纪录）。

**合并规则（v1.5 新增，硬）**

**先归并 → 再倒排 → 后编号。** 判断「是否重复」的标准是：**去掉来源后，两条的"事实内核"是否相同**——相同就必须合并。

| 情形 | 处理 |
|---|---|
| 同一事件的多家报道 | 合 1 条，来源用「/」列全 |
| 同一主体的连续动作（间隔 <6 小时且同一逻辑，如「董事长提议回购」→「董事会通过回购」） | 合 1 条，时间取**最新** |
| 同一主题的多条（如三家公司同日回购） | **可**合并为「多家公司回购」，但须列明主体与各自金额 |
| 同一政策的多篇解读 | 只保留政策事实 1 条；不同机构解读归「观点」，最多 2 条 |
| 同一数据的初值与修正值 | 只留最新值，旧值不单列 |

**禁止的合并（宁可分开写）**：
- 金额/规模差一个数量级的主体并成「多家」（把 10 亿和 1000 万并成「多家公司回购」＝丢信息）
- 方向相反的两件事并成一条（「A 涨停」与「B 跌停」）
- 把观点与事实并成一条

**合并后必做**：重新**连续编号**（1..N 无跳号）、同步更新「资讯与行情的对应」表里的引用编号、复核 6.1 条数是否仍达下限（合并导致减少是正常的，低于下限要补检索）。

**填写规则（硬）**
- 每条必须带**来源名 + 发布时间**；无法确认发布时间的挂 `[待补⚠]`，不得写成事前日程。
- 「事实」与「观点」必须分列：观点要写出主体（机构名/人名），禁止无名「机构认为」「市场预期」。
- 简述只写发生了什么，**不写「利好/利空」「有望」「预计」「将提振」**，不推断对 A 股的影响。
- 涉及数字时保持与第 2 节同一口径；带 `[源冲突⚠]` 的资讯直接用采信值，不展开各源。
