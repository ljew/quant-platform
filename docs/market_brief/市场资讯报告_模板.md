## 填写规则（生成时必须遵守，不随报告输出）

### R1 · 时区、交易日与每日运行
- 全文统一**北京时间（UTC+8）**，生成时点在报告头写全。
- 美股必须写「美东 MM-DD 收盘 / 北京时间 MM-DD 凌晨」，**禁止只写一个日期**。
  日内跨夜最容易把「美东周四暴跌」错记成「周五暴跌」，本次已实际踩到。
- 自动化**每日运行（含周末）**。每次先判定 `是否交易日`：
  - **交易日**：按本时段正常取数。
  - **非交易日（周末/节假日）**：报告头标注「休市」+ 原因 + 下一交易日；第 2 节引用**上一交易日**收盘数据并逐项标日期，第 3 节改为「上一交易日回顾 + 休市期间消息面」，第 4 节观察点指向下一交易日，第 5 节以休市期间资讯为主。
    **严禁虚构当日行情、盘中快照、半日/全天成交额**；本时段确无新增行情要明写「本时段无新增行情」，不得用旧数据冒充新数据。
- 周一早间版覆盖窗口 = 上周五 A 股收盘 → 周一开前，含周末消息面与周五美股。周六/周日各版覆盖窗口 = 周五 A 股收盘 → 该版生成时点。

### R2 · 字段三要素（硬规则）
每个数字必须同时给出：**数据对应日期 + 口径 + 数据源标签**，三者缺一不进结论。
- 利率类尤其要写明口径：中债收益率曲线 10Y / 活跃券 260016 / 银行间收盘 / 美债 10Y，**不同口径不可混用比较**。
- 涨跌幅写清「相对上一交易日收盘」还是「相对结算价」（期货常用结算价，易差 1–2 个 tick）。
- 「-2.96%」这类**相对变动百分比**与「-2BP」不可混写，看到先换算再引用。

### R3 · 溯源标签（字段级，不写整篇一个标签）
| 标签 | 含义 |
|---|---|
| `[通达信✓]` | tdx-connector 实时/收盘快照 |
| `[tushare✓]` | Tushare pro API（收盘价/估值/指数日线） |
| `[neodata✓]` | 国泰海通 neodata-financial-search |
| `[腾讯✓]` | 腾讯 westock-data CLI |
| `[中债✓]` | 中国债券信息网日评（收益率曲线、公开市场） |
| `[公开媒体✓ 来源·日期]` | 财经媒体，必须带**来源名 + 发布时间**，机构观点必须带 publishTime |
| `[待补⚠]` | 未取到，**严禁估算或编造** |
| `[源冲突⚠]` | 多源不一致，已按来源层级采信；**只在该字段打标，不展开比对过程** |

### R4 · 源校验门（三源交叉，**动作必做、过程不展示**）
- 同一字段两源及以上一致 → 直接采信，**不标注**「多源一致」这类过程信息。
- 多源冲突 → **不自行拍板**：按「有无完整时点标注 / 有无交叉印证 / 来源层级」选定采信值，
  正文直接用采信值，仅在该字段挂一个 `[源冲突⚠]`（8 个字符，不展开各源数值）。
  **不再单列校验表** —— 读者只看结论，不看比对过程。
- 能做的跨市场换算校验要做（例：COMEX 黄金 USD/oz ÷ 31.1035 × USD/CNY ≈ 沪金 元/克），
  这是最便宜的假数据探测器；通过就不写，偏差超过 0.5% 才在当节小结里点一句。
- 涨跌家数按**交易所口径**相加（沪 + 深 + 北），**不得把创业板/科创板再加一遍**（属深/沪子集，重复计算）。

  实测 11-06：`25.63, -2.54, -9.02%`，昨收 28.17。
- **替代源全部试过、都不可用**，不要再浪费时间：
  yfinance（1.5.1 已装）→ Yahoo 限流 `YFRateLimitError`；Yahoo 直连 → sad panda 拦截页；
  stooq → JS 验证；东财 `m:100` 国际指数 63 个里**没有**费半与 VIX；腾讯 `usSOX`/`usPHLX` 无匹配、
  `usVIX` 数据停在 2026-09-15（陈旧，不可用）。

**2.1 境内表不允许留空**：20 日 / YTD / 成交额都可由 tushare `index_daily` 历史算出——
20 日 = 收盘 / 21 根前收盘 − 1；YTD = 收盘 / **上年最后一个交易日**收盘 − 1。
成交额用 `index_daily.amount`（单位千元，÷1e5 得亿元），注意它是**指数成分股口径**，
深成指（500 只）4650 亿 ≠ 深市总成交 8852 亿，两者不可混用。

### R6 · 内容边界（重要）
- 本报告是**信息收集与事实整理**，产出「状态判定 + 可验证的观察点/触发条件 + 资讯简述」。
- **不产出涨跌方向预测、不产出买卖建议；全篇不设裁决区、不设签字栏，不做方向裁决。**
  这与 `a-share-three-source-report` methodology §0「AI 不做最终裁决」一致。
- 方向性判断属发现类（F 通道），归 **A股研究团队**；验证类结论走衡析的假设卡流程。
  本报告不替代其中任何一条，也不得用资讯综述冒充研究结论。
- 引用机构观点必须是**原文可追溯**的公开表述，带来源与日期；不得概括成无名「机构认为」。

### R8 · 每节小结（v1.4 新增，v1.6 修订，硬要求）
第 1 节、2.1–2.5 各子节、第 3 节末尾必须有且**只有一句** `**小结**：…`，回答「这节数据说明了什么」（共 7 处）。
其中第 1 节那句是**全篇结论**（与 1.2 状态判定同源），不得与其余各节小结矛盾。

写法约束（越界即不合格）：
- **只描述状态与相对关系**。正例：「缩量普跌，卖压不重但买盘更弱，资金端逆势流入」。
- **禁止**：涨跌预测、概率、「利好/利空」「有望」「预计」「将启动」、买卖建议、目标位。
- **必须能被本节数字直接支撑**，不许引入本节没出现过的新事实。
- 一句话，**≤60 字**；不重复表格里的数字，只给结论。

**class 用途速查**

| class | 用在哪 | 作用 |
|---|---|---|
| `grid2` / `grid64` | 并排容器 | 两栏栅格，`stretch` 等高 |
| `col` | 栅格内每栏 | 弹性列，让 `.sum` 贴底 |
| `num` | 2.1–2.4 数值表 | 数值列按内容收缩 |
| `state` | 1.2 状态判定 | 读数列 nowrap + 判据左对齐 |
| `t-wrap` | 长文本表 | 允许单元格折行 |
| `news` | 资讯表 | 短列 nowrap |
| `map` | 对应表 | 首列收缩 |
| `cols2` | 2.5 要点 | 两栏横排 |
| `src` / `note` / `sum` | 注释 / 提示 / 小结 | 见附录 A |
| `tags` | 多个溯源标签 | 防拆行 |
| `up` / `down` | 涨跌 | 暗红 / 暗绿 |
