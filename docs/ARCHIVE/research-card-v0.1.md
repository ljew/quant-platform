# 研究卡（Research Card）标准 v0.1 —— 提案，未实施

> 目的：把「一个策略/因子从想法到生产」变成一张标准卡片 + 一条固定流水线。
> 任何新研究进来都走同一条路，成熟一个上一个，不靠记忆和感觉。
> 依据：《量化交易》五支柱 + 本平台 2026-09~10 的实际运行经验。

## 卡片字段（8 项，缺一不可）

| # | 字段 | 内容要求 |
|---|------|---------|
| 1 | **假设** | 一句话：为什么会有超额？（说不出假设的不准入库） |
| 2 | **数据与口径** | 用什么数据、T+1 建仓、超额基准（全市场等权）、样本区间 |
| 3 | **证据** | 三窗口超额（240/120/60 日 或 90 日滚动）+ 样本量 n + 运气折价后 t 值 |
| 4 | **成本** | 换手级别 + 扣成本后超额是否仍为正 |
| 5 | **容量与拥挤** | 与现有因子/策略的相关性；信号密度是否可持续 |
| 6 | **失效条件** | 预先写明：出现什么情况就认为它失效（如「90 日窗口连续两周为负」） |
| 7 | **状态** | 观察 → 候选 → 启用 → 降级 → 退役（状态机见下） |
| 8 | **决策历史** | 每次状态迁移的日期与理由（自动进决策文档） |

## 状态机（迁移条件全部可机检）

```
        新研究提交
            │
            ▼
        【观察】  只记录、不交易、不进每日观点
            │  样本 ≥ 20 且 90 日超额 > 0
            ▼
        【候选】  进归因页展示，仍不交易
            │  三窗口全正 + 运气折价后 t 达标 + 扣成本仍为正 + 与现有低相关
            ▼
        【启用】  进每日信号/生产计算（弱 → WATCH 不建仓的闸门仍然生效）
            │  触发失效条件
            ▼
        【降级】  停止建仓，只观察；连续 4 周未恢复 →
            ▼
        【退役】  归档，留历史，不再出现在任何列表
```

安全边界不变：**升级自动执行，降级出建议由人确认**（除非用户另行授权）。

## 三个真实案例验证（数据：2026-10-03 复盘 + 240 日校准）

### 案例 A：high_tight_flag（高紧旗形）—— 当前 strong
1. 假设：放量突破长期整理平台后的强势股有动量延续
2. 口径：T+1 开盘建仓，T+10 收盘卖出，超额 vs 全市场等权
3. 证据：90 日 T+10 超额 **+2.14%**（n=349）；240/120/60 日三窗口 +1.77/+1.66/+1.80，全正且稳定
4. 成本：信号稀疏（n=349/90 日），换手低，扣成本后仍为正
5. 容量：信号稀疏天然不拥挤
6. 失效条件（预设）：任一滚动窗口转负即降级复核
7. 状态：**启用** ✅
8. 历史：2026-09-30 复盘确认维持 strong（卡片能完整描述）

### 案例 B：chan_buy（缠论买点）—— 当前 neutral
1. 假设：缠论结构买点捕捉趋势拐点
2. 口径：同上
3. 证据：90 日 T+10 超额 **+0.75%**（n=17,274），T+5 −0.03%——短期无超额，中期弱正
4. 成本：信号密集（日均 ~190 条），换手高，扣成本后边际存疑
5. 拥挤：信号密度高，需进一步分层过滤
6. 失效条件：90 日窗口转负
7. 状态：**候选**（当前 neutral 档正好对应——启用但未达 strong，建议卡片制下归为候选：可建仓但需更高确认门槛）
8. 历史：2026-09-30 新增，样本积累中（卡片能完整描述，且暴露了 T+5 无超额这个待解问题）

### 案例 C：turtle_trade（海龟突破）—— 当前 weak
1. 假设：突破 N 日高点后有趋势延续
2. 口径：同上
3. 证据：90 日 T+10 超额 **−2.66%**（n=11,908），240 日 −0.24%——大样本持续为负
4. 成本：不适用（已无超额）
5. —
6. 失效条件：已触发（90 日负 + 240 日负）
7. 状态：**降级**（当前 weak = 不建仓）→ 若连续 4 周未恢复正超额 → 退役
8. 历史：2026-09-30 复盘降级（卡片能完整描述，且给出了明确的下一步：4 周后自动进入退役评估）

## 验证结论

三个不同状态的策略都能被这 8 个字段干净描述，且状态机迁移条件与现有机制
（质量分级、运气折价、每周复盘、决策留痕）一一对应，不需要发明新东西，
只需要把它们**统一成同一个对象**。因子同样适用（字段 3 换成 IC/ICIR 口径）。

## 落地顺序（确认后执行，每步可独立交付）

1. 定义卡片表结构（research_cards）+ 迁移现有 9 策略 + 注册表因子（纯数据工作，不动逻辑）
2. 每日信号/因子生产改为只读「启用」状态的卡（逻辑等价替换）
3. 每周复盘自动更新证据字段 + 按状态机出迁移建议
4. 前端「研究卡」列表页（替代现在的因子检验页部分功能，一个卡片一个卡片看）
