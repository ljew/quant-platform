1. 三分钟上手

  1. 打开平台首页，默认落在「今日观点」——这里有今天最值得看的内容。
  2. 左侧导航只有四个入口：今日观点 / 策略研究 / 组合跟踪 / 数据中心。日常 90% 的时间你只需要第一个。
  3. 右下角（数据中心 → 自动研究）能看到平台昨晚替你干了什么：挖了几个因子、有没有新的好因子自动上岗。
  4. 每周六上午会收到一封复盘邮件：这周信号表现如何、哪些策略在走弱、建议怎么处理。
核心用法一句话：每天看一眼「今日观点」，每周看一眼复盘邮件，其余全部自动。

2. 四个入口怎么用

☀ 今日观点

  • 今日观点：系统综合信号、行情、研究结论给出当日要点，打开即有观点。
  • 行情看板：指数、板块、市场宽度等行情总览。

⚗ 策略研究

  • 回测：对策略/组合跑历史回测（严格 T+1、PIT 成分池，无未来函数）。
  • 参数寻优：网格/迭代搜索策略参数的最优区间。
  • 因子检验：查看因子的 Rank IC、分层收益、换手容量；GP 挖掘已熔断（2026-10-08），该入口暂不可用。

◷ 组合跟踪

  • 模拟盘：按信号自动镜像的模拟组合，T+1 开盘成交，看净值与持仓。
  • 信号组合：每日信号明细——每只股票的动作、连续天数、命中策略、质量档。
  • 归因分析：按策略拆解 T+1/T+5/T+10 的胜率与超额收益，谁在赚钱一目了然。

⇉ 数据中心

  • 自动研究：自动挖矿 + 自动复盘的状态台——它昨晚干了什么、下次什么时候跑、开关在哪，还能直接看复盘报告。
  • 数据管道：Bronze→Silver→Gold 数据流全景与手动触发。
  • 系统监控：健康分（百分制）、告警列表、管道运行记录、节假日静默开关。
  • 研究驾驶舱：研究流水线的运行编排与事件日志。

4. 信号怎么读

每只股票每天得到一个动作：

动作含义你该怎么理解
BUY_STRONG连续多日命中有效策略符合建仓条件（模拟盘次日开盘自动买入）
WATCH确认中 / 策略偏弱 / 短线走弱只看不动；策略偏弱时明确标注「不建仓」
REDUCE跌破 MA20，趋势转弱持有的话考虑减仓
EXIT信号消失不再跟踪
NEW首次出现持续性待确认

每条信号还带质量档：strong 长期验证有效 · neutral 观察中 · weak 历史超额偏弱。weak 档策略产生的信号不会变成 BUY_STRONG，这是 2026-09-30 复盘后的重要防线。

5. 自动研究：挖矿与复盘

已停GP 挖矿已熔断（2026-10-08）：实测 37 个输出全是单变量变体、无交互项，26/37 为负 IC，其中 7 个曾被误判「可用」进入注册表。周六的自动复盘仍在正常运行。详见架构文档第 6 节。

它在挖什么

GP 挖矿已于 2026-10-08 熔断，以下为其原设计（当前不执行）。原方案：每个交易日 20:47 用遗传规划在因子表达式空间进化搜索，评估数十个候选，精英按「优秀/可用/弱/无效」评级：

  • 优秀 → 自动启用，明天就参与全市场计算（无需你操作）；
  • 可用 → 留在候选池，等你有空时看一眼；
  • 弱/无效 → 直接丢弃，只留运行记录。

复盘报告怎么看

每周六的报告回答三个问题：① 哪个策略最强/最弱（90 日滚动窗口）；② 模拟盘组合表现；③ 因子库盘点与处置建议。注意：策略降级目前只出建议，是否执行由你决定——这是故意的安全设计。

想关掉或调参

「数据中心 → 自动研究」页有四个开关（挖矿/复盘/优秀自动上岗/邮件）和时间、种群规模等参数，改完即时生效。

6. 常见问题

Q：今天数据没更新？
先看是不是交易日（非交易日停更正常，监控页会显示「节假日静默中」）。是交易日但没更新：数据中心 → 系统监控 → 「▶ 立即运行管道」手动触发，健康分会告诉你卡在哪一环。

Q：网站打不开？
后端由系统服务托管，一般会自动运行。稍等 30 秒刷新；还不行就重启电脑（系统服务会随开机自启）。

Q：想恢复某个被降级的策略？
找维护者改 backend/app/services/xq/strategies.py 里的 STRATEGY_QUALITY 定档即可，重启后端生效。每周复盘会持续跟踪它的窗口表现。

Q：复盘邮件没收到？
邮件需要配置发件通道；未配置时系统只记录日志不报错，报告照样生成，可在「自动研究」页点「看报告」直接查看。

Q：LLM 功能（因子释义等）怎么配？
在 LLM 配置页维护供应商和 key，保存即时生效，无需重启。

7. 边界与免责声明

  • 本平台不含实盘交易，所有买卖动作只发生在模拟盘。
  • 所有信号、回测、归因结果基于历史数据统计，不构成投资建议；过往超额不代表未来。
  • 数据来自公开数据源（akshare / tushare），偶发的源端缺失会自动补抓，但极端情况下可能延迟。
  • 全部数据仅存本机，不上传。
