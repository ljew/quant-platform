1. 三分钟上手

  1. 浏览器打开 http://localhost:8000/ —— 唯一需要记住的地址（前端页面和后端服务都在这里，开机自启）。默认落在「今日观点」。
  2. 左侧导航只有四个入口：今日观点 / 策略研究 / 组合跟踪 / 数据中心。日常 90% 的时间你只需要第一个。
  3. 右下角（数据中心 → 自动研究）能看到平台昨晚替你干了什么：跑了哪些研究、信号有没有变化、复盘结论如何。
  4. 每周六上午会收到一封复盘邮件：这周信号表现如何、哪些策略在走弱、建议怎么处理。需要你做决定的事，也会在「策略研究 → 研究卡」页面顶部以黄色横幅等你确认。
核心用法一句话：每天看一眼「今日观点」，每周看一眼复盘邮件和研究卡横幅，其余全部自动。

2. 四个入口怎么用

☀ 今日观点

  • 今日观点：系统综合信号、行情、研究结论给出当日要点，打开即有观点。
  • 行情看板：指数、板块、市场宽度等行情总览。

⚗ 策略研究

  • 研究卡（核心）：一个策略/因子 = 一张卡片。顶部状态机一眼看清「几个策略在动钱」；点卡片进详情页看完整分析（按月超额、信号日历、每只标的的判定理由）；降级/退役建议在页面顶部横幅一键确认。平时不用看，有建议它会找你。
  • 回测寻优：单次回测 + 批量参数寻优（严格 T+1、PIT 成分池，无未来函数）。
  • 因子实验室：造新因子的地方（表达式 / GP 挖掘 / AI 生成）；造好了去研究卡上岗。

◷ 组合跟踪

  • 模拟盘：按信号自动镜像的模拟组合，T+1 开盘成交，看净值与持仓。
  • 信号组合：每日信号明细——每只股票的动作、连续天数、命中策略、质量档。
  • 归因分析：按策略拆解 T+1/T+5/T+10 的胜率与超额收益，谁在赚钱一目了然。

⇉ 数据中心

  • 自动研究：自动挖矿 + 自动复盘的状态台（它昨晚干了什么、下次什么时候跑、开关在哪），内含「流水线实况」子页签看 8 步编排的运行细节。
  • 数据与系统：数据管道（Bronze→Silver→Gold 全景与手动触发）+ 系统服务（健康分、告警、节假日静默开关）。

4. 信号怎么读

每只股票每天得到一个动作：

动作含义你该怎么理解
BUY_STRONG连续多日命中有效策略符合建仓条件（模拟盘次日开盘自动买入）
WATCH确认中 / 策略偏弱 / 短线走弱只看不动；策略偏弱时明确标注「不建仓」
REDUCE跌破 MA20，趋势转弱持有的话考虑减仓
EXIT信号消失不再跟踪
NEW首次出现持续性待确认

每条信号还带质量档：strong 启用卡（长期验证有效） · neutral 候选卡（试用中） · weak 降级/退役卡。weak 档策略产生的信号不会变成 BUY_STRONG——这是研究卡状态机在生产端的闸门，2026-10-08 起档位直接由卡片状态驱动，不再需要改代码。

5. 自动研究：挖矿与复盘

平台每天/每周自己干活，你只看结果。研究卡是这套闭环的载体：挖出的因子自动建卡、复盘自动更新证据、状态机自动执行升级，降级/退役出建议等你确认。

它在挖什么

每个交易日 20:47 用遗传规划在因子表达式空间小规模搜索，精英按「优秀/可用/弱/无效」评级（2026-10-08 起带运气折价 t 门槛）：

  • 优秀且简单（复杂度 ≤4）→ 自动启用并建研究卡，明天就参与全市场计算；
  • 优秀但复杂 / 可用 → 留在候选卡，等你有空时看一眼；
  • 弱/无效 → 直接丢弃，只留运行记录。

复盘报告怎么看

每周六的报告回答三个问题：① 哪个策略最强/最弱（90 日滚动窗口，含 t 值）；② 模拟盘组合表现；③ 研究卡状态变化——升级已自动执行，降级/退役以建议形式列出。确认建议不用改代码：打开「策略研究 → 研究卡」，页面顶部横幅点「同意」即可，下一次跑批生效。

想关掉或调参

「数据中心 → 自动研究」页有四个开关（挖矿/复盘/优秀自动上岗/邮件）和时间、种群规模等参数，改完即时生效。

6. 常见问题

Q：今天数据没更新？
先看是不是交易日（非交易日停更正常，数据中心 → 数据与系统会显示「节假日静默中」）。是交易日但没更新：数据与系统 → 数据管道手动触发，健康分会告诉你卡在哪一环。

Q：网站打不开？
确认地址是 http://localhost:8000/（7100 是开发临时端口，平时不开）。后端由系统服务托管，稍等 30 秒刷新；还不行就重启电脑（服务随开机自启）。

Q：想恢复某个被降级的策略？
「策略研究 → 研究卡」找到那张卡，点进详情页，底部「人工状态迁移」选「候选」填理由即可，下一次跑批生效，无需改代码。每周复盘发现它超额转正时也会自动升回候选。

Q：复盘邮件没收到？
邮件需要配置发件通道；未配置时系统只记录日志不报错，报告照样生成，可在「自动研究」页点「看报告」直接查看。

Q：LLM 功能（因子释义等）怎么配？
在 LLM 配置页维护供应商和 key，保存即时生效，无需重启。

7. 边界与免责声明

  • 本平台不含实盘交易，所有买卖动作只发生在模拟盘。
  • 所有信号、回测、归因结果基于历史数据统计，不构成投资建议；过往超额不代表未来。
  • 数据来自公开数据源（akshare / tushare），偶发的源端缺失会自动补抓，但极端情况下可能延迟。
  • 全部数据仅存本机，不上传。
