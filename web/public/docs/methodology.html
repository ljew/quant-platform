书名五个词就是量化交易的流程顺序：机器先导入数据，然后做分析， 用模型在数据与决策之间搭桥，用优化把决策变成最优策略，最后用算法把策略执行出来。 —— 第 1.5 节

一、对本平台最相关的六个思想

1. 数据是五支柱之首（第 1.5 节）

原书明确：无论从套利视角还是有效市场视角，「数据」都是量化交易最重要的一环。垃圾数据喂养出精致的错误。

→ 本平台对应：Bronze→Silver→Gold 三层管道、每日 19:00 自动 ETL、断供自愈、质检闸门（数据不合格阻断后续流水线）、健康度引擎把「采集层」权重设为最高的 35%。

2. 样本内 / 样本外评估 + 多重检验（第 2.8.5 节）

原书警示：策略在样本内表现好可能是数据挖掘偏差；测试的策略越多，「幸存者」越是运气——需要多重检验校正（Bonferroni / White 现实检验的思想）和真正的样本外验证。这直接回应「回测好 ≠ 未来好」。

→ 本平台对应：GP 挖矿的精英评级阈值（宁缺毋滥：56 候选 5 精英全「弱」就一个不进库）；策略定档要求多窗口一致（240/120/60 日三窗口，正是样本外思想的滚动版）；每周复盘用最近 90 日窗口对旧结论持续再检验。

3. 参数不确定性（第 2.5、3.3.6 节）

估计的参数（均值、协方差、因子收益）本身有误差，把点估计当真值做优化会放大误差。原书给出贝叶斯/缩减（shrinkage）、Black-Litterman、Bootstrap 重抽样（NPEB）等处理框架。

→ 本平台对应：参数寻优看「最优区间」而非单个最优点；high_tight_flag 维持 strong 的理由正是三窗口全正（对窗口选择不敏感 = 对参数扰动稳健）；rps_breakout 240 日强、90 日弱 → 降级而非删除。

4. 交易成本与约束是策略的一部分（第 3.2 节）

超额收益 α 的来源必须扣除交易成本、冲击成本和买卖限制后还活着才算数；多期环境下存在交易成本时的动态再平衡是第 3 章的核心问题。

→ 本平台对应：信号归因口径 T+1 开盘建仓、T+10 收盘卖出（计入隔夜与延迟）；因子检验包含换手与容量；A 股 T+1 制度直接写进组合镜像规则。

5. 模型是数据与决策之间的桥（第 1.5、2.6-2.7 节）

从随机游走到鞅模型、ARIMA/GARCH、多因子定价——模型的价值不在复杂度而在「能否支撑更好的决策」。鞅回归模型把可预测性显式纳入组合优化（最优信息比率）。

→ 本平台对应：因子不做成预测模型本身，而是进入「质量分级 → 信号动作」的决策链；弱因子不进库、弱策略不建仓，模型的输出必须能落到动作上。

6. 策略风险与操作风险（第 8.5 节）

原书把风险分两类：策略风险（模型错了、环境变了）和操作风险（系统挂了、数据断了、流程错了）。两者都要制度化监控。

→ 本平台对应：策略风险 → 每周复盘 + 质量降级机制 + 决策留痕；操作风险 → 健康度引擎、节假日静默（区分「预期停更」与「真故障」）、调度幂等防重、决策记录活文档。

三、研究纪律（嵌入自动研究流程的硬规则）

以下五条已作为「数据中心 → 自动研究」页面的常驻纪律卡展示，供每次查看挖矿/复盘结果时对照：
  1. 数据先行：任何结论之前先问数据是否干净、新鲜、无未来函数。
  2. 样本外才算数：单窗口、单区间的亮眼结果一律视为候选，需滚动窗口复核。
  3. 挖得多，门槛就得高：批量挖掘的「好结果」默认有运气成分，评级从严。
  4. 扣除成本还活着才是 α：换手、延迟、冲击成本之后的超额才算数。
  5. 错了要留痕：每次升降档、每次修复都记入决策文档，可回溯、可复盘。

四、待办（按价值排序）

  • 多重检验校正：挖矿批次输出 deflated Sharpe 或等价的「运气折价」提示，评级时再降一档保守度。
  • 组合层优化：信号组合从等权镜像升级为带成本约束的均值-方差/风险平价加权（第 3 章框架）。
  • 参数置信区间：寻优结果附 Bootstrap 置信带，替代单点最优报告。
