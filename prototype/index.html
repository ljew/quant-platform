重构说明

11 个页面 → 4 个入口，按「每日使用路径」而非「技术模块」组织

原则 1 · 打开就有观点

默认页直接回答「今天买什么、卖什么、为什么」。信号、资讯、行情原来分散在 3 个页，现在聚合为「今日观点」。

原则 2 · 研究不出工作台

回测 → 寻优 → 因子检验是同一个「验证想法」的循环，合并为「策略研究」的 3 个 Tab，参数和标的一键互带。

原则 3 · 后台退居后台

管道、监控、驾驶舱是运维视角，个人用户 99% 的时间不需要。合并为「数据中心」，正常时只剩导航栏一枚状态徽章。

页面映射（旧 → 新）

原页面（11）新位置（4）处理方式
信号中心→今日观点升级为核心：操作卡 + 信号明细 + 一句话理由
资讯中心→今日观点收编为右侧快讯栏
行情看板→今日观点K 线改为信号行的抽屉式展开，指数概览变顶部条
研究驾驶舱→今日观点 / 数据中心8 步流水线降级为状态徽章；人工闸门保留在数据中心
策略回测→策略研究 · 回测 Tab功能不变，并入工作台
参数寻优→策略研究 · 寻优 Tab功能不变；「一键落地」直达模拟盘
因子挖掘→策略研究 · 因子 Tab功能不变，更名「因子检验」对齐心智
模拟盘→组合跟踪与归因合并，回答「策略在实盘环境下行不行」
归因分析→组合跟踪并入，信号有效性直接标注在今日观点页
数据管道→数据中心合并，保留资产健康度与一键修复
系统监控→数据中心合并为「系统运行」卡

不改的部分

后端 API、数据库、策略引擎、每日流水线全部不动——这次只重组前端信息架构。 旧 `frontend/` 三个静态页（index / backtest / paper）已被 React 版完全覆盖，实施时可直接删除。
